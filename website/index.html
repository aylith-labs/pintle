LESS RECONFIGURATION

A familiar route.
A better view.

Keep existing labels

Docker discovery reads Pintle, Traefik and Caddy label formats. Host and path routes connect to your services without a second set of labels.

Use a file when it fits

Define routes in YAML. Static-only mode stays on loopback, without Docker discovery, TCP listeners or SNI passthrough. Invalid file reloads keep the last accepted routes.

Know what is running

The embedded dashboard shows routes, requests and topology. Runtime self-description and the doctor command report the actual configuration and missing expected hosts.

Pass through deliberately

Configured SNI domains can pass to another proxy without TLS termination. TCP routes can terminate TLS for local database services. These modes use the full Docker or host-native setup.

THE RIGHT TOOL FOR THIS JOB

Local HTTPS.
Explicit boundaries.

Choose your setup

Start with loopback static-only routes on unprivileged ports. Docker discovery needs access to the Docker daemon and a shared network. Host-native redirection of ports 80 and 443 requires administrator privileges.

Keep the browser’s trust

Generate local certificates with mkcert and install its local CA according to its instructions. Install the local CA before opening a route in your browser.

A development proxy

Use Pintle for your local development environment. It supplies neither public ACME certificates nor replica load balancing, upstream health checks, rate limiting or authentication middleware. A public edge needs the appropriate protections.

Your configuration stays local

The downloadable archive contains no private routes, certificates, keys or user data. The runtime dashboard describes your local setup; restrict access and do not expose it as a public service.
